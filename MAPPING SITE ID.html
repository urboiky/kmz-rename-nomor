Catatan pencocokan

Hasil selalu mengikuti urutan placemark HOME dari atas ke bawah di KMZ. Placemark dengan prefix ?- tetap dimasukkan, tetapi SITE ID otomatis - tanpa pencocokan database. Placemark lain dicocokkan memakai NAMA JALAN + NOMOR RUMAH. Untuk nomor rumah duplikat, sistem mengambil baris database berikutnya yang belum terpakai sehingga satu baris database tidak digunakan dua kali.
